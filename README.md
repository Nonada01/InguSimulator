# 🇰🇷 한반도 인구 디지털 트윈 시뮬레이터

미적분 기반 실시간 인구 유동 시뮬레이션

## 🚀 실행 방법

1. `index.html` 파일을 웹 브라우저로 열기
2. 크롬, 파이어폭스, 엣지, 사파리 등 모던 브라우저에서 실행 가능
3. 인터넷 연결 필요 (React, Tailwind CSS CDN 사용)

## 📊 주요 기능

### 1. 인구 유동 지도
- 한반도 7개 행정구역 색상 구분
- 9개 주요 도시 인구 시뮬레이션
- 실시간 인구 증감 표시

### 2. 환경 & 산업화
- 산업화 수준 시각화
- 공장 애니메이션
- 오염도 실시간 모니터링

### 3. 통계 그래프
- 인구 변화 추이
- 오염도 변화 추이

## 🎮 정책 조절

### 9가지 정책 슬라이더
1. **출산 장려** (200억/틱)
2. **이민 정책** (150억/틱)
3. **주택 공급** (300억/틱)
4. **일자리 창출** (250억/틱)
5. **교육 투자** (200억/틱)
6. **의료 복지** (250억/틱)
7. **교통 인프라** (300억/틱)
8. **산업화 투자** (400억/틱) - GDP↑, 오염↑
9. **환경 보호** (350억/틱) - 오염↓↓

## 📐 수학 모델

- **로지스틱 방정식**: `dP/dt = rP(1-P/K)`
- **도시간 확산**: 인구 밀도 차이에 비례
- **경제 모델**: GDP = f(인구, 산업화)
- **환경 모델**: 오염 = 산업배출 + 인구배출 - 정화

## 💡 플레이 팁

1. 초반에 산업화를 높여 세수 확보
2. 오염도가 높아지면 환경 정책 투자
3. 국고가 부족하면 즉시 지출 감축
4. 균형잡힌 포트폴리오 유지
